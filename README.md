Entry for the make.fun bounty [One-Line Office Joke Laugh-Off](https://make.fun/c/u-suzy-one-line-office-joke-laugh-off-f574ac73).

`main.py` (Python 3, standard library only) writes one original one-line
office joke to `/output/entry.txt`. The line was picked from twelve
candidates judged locally against the published brief; see `CANDIDATES.md`.

Run it with:

```sh
python3 main.py
```
